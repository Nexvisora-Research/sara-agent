# Keyboard Shortcuts

All shortcuts can be rebound in **Settings → Keyboard Shortcuts**.

## Navigation

| Shortcut | Action |
|----------|--------|
| `Ctrl+K` | Open command palette |
| `Ctrl+,` | Open settings |
| `Ctrl+N` | New session |
| `Ctrl+Shift+N` | New session in window |
| `Ctrl+Tab` | Next session |
| `Ctrl+Shift+Tab` | Previous session |
| `Ctrl+1`–`9` | Switch to recent session 1–9 |

## Composer

| Shortcut | Action |
|----------|--------|
| `Enter` | Send message |
| `Shift+Enter` | Insert newline |
| `Ctrl+Shift+Enter` | Steer the running turn |
| `Ctrl+Shift+U` | Send next queued turn |
| `@` | Reference files, folders, URLs |
| `/` | Slash command palette |
| `Esc` | Close popover / cancel run |
| `Up/Down` | Cycle input history |

## View

| Shortcut | Action |
|----------|--------|
| `Ctrl+B` | Toggle sessions sidebar |
| `Ctrl+Shift+B` | Toggle file browser |
| `Ctrl+Shift+F` | Show file browser |
| `` Ctrl+` `` | Show terminal |
| `Shift+X` | Toggle light / dark mode |

## Profiles

| Shortcut | Action |
|----------|--------|
| `Ctrl+Shift+P` | Next profile |
| `Ctrl+Shift+O` | Previous profile |
| `Ctrl+Shift+A` | Toggle all-profiles view |
| `Ctrl+Alt+1`–`9` | Switch to profile 1–9 |

## Session

| Shortcut | Action |
|----------|--------|
| `Ctrl+Shift+S` | Search sessions |
| `Ctrl+Shift+P` | Pin/unpin current session |

## Voice

| Shortcut | Action |
|----------|--------|
| `Space` (while listening) | End current voice turn |

> **Tip:** Press `Ctrl+K`, then type "shortcuts" to see the full, up-to-date list from inside the app.
